## Overview
`indextts2-mlx` is a torch-free, Apple-Silicon-native port of IndexTTS-2, a zero-shot text-to-speech system that clones voice from a short reference clip. The architecture follows the original pipeline: W2VBert extracts semantic features from reference audio, CAMPPlus computes a speaker style embedding, a GPT-v2 autoregressive model decodes text tokens into speech codes, a Conformer-based Conditional Flow Matching (DiT/CFM) module synthesizes mel-spectrograms, and BigVGANV2 converts mels to waveforms. All stages are implemented as MLX Swift modules in `IndexTTS2Kit`; Python scripts in `scripts/` handle one-time weight conversion from PyTorch checkpoints.

## Build / test
- **build**: `./build.sh [Debug|Release]` — wraps `xcodebuild`, which is required: plain
  `swift build` does not compile MLX's Metal shaders (`default.metallib`). Binary lands at
  `.build/xcode/Build/Products/<config>/indextts2`; Debug is the default and Release is
  ~2.3x faster, so point real batch jobs at the Release binary explicitly.
- **test**: no test target. `indextts2 --smoke` is the smoke check (module loading + one
  forward pass); the `scripts/ref_*.py` NumPy references are the correctness ground truth.

## Conventions
- All ML layers use `MLX` arrays (NLC layout: batch × time × channels); reshape to `NCL` (channels-first) only at convolutional boundaries.
- Models are loaded from `.safetensors` files via `MLX.loadArrays`; weight key mapping from PyTorch names lives in `Loading.swift`.
- `callAsFunction` is the Swift idiom for `forward`; layers conform to `MLXNN.Module`.
- Python `ref_*.py` scripts serve as ground-truth for preprocessing; run them against a `.wav` and compare to Swift output when porting new stages.
- The `--smoke` CLI flag exercises module loading and a single forward pass without requiring a real reference audio file.
